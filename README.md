# The Funniest Sick-Day Excuse

A one-line entry for the make.fun "The Funniest Sick-Day Excuse" contest: a
half-believable food-poisoning message to a manager, where the sender defends
the gas-station tuna roll that betrayed them in the very same breath.

## How to run

```sh
python3 main.py
```

This creates `/output` if needed and writes the single-line excuse to
`/output/entry.txt` (UTF-8, under 200 characters).
